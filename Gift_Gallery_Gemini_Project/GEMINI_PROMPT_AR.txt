طوّر مشروع Gift Gallery المرفق اعتمادًا على الملفات الموجودة، ولا تكتفِ بوصف أو تصميم شكلي. ابدأ بفحص كل الملفات ثم أعد المشروع كاملًا قابلًا للتشغيل.

المطلوب:
1) حافظ على تصميم Gift Gallery الفاخر بالعربية وRTL، المتجاوب للموبايل والكمبيوتر.
2) أنشئ لوحة إدارة حقيقية لإضافة/تعديل/حذف/إخفاء/نشر الهدايا وإدارة التصنيفات والبانرات والأسعار والترتيب.
3) اربط تسجيل دخول Google OAuth الحقيقي، ولا تمنح صلاحية الإدارة إلا لبريد المالك الذي أضعه في إعدادات الخادم. لا تضع أسرار OAuth أو GitHub tokens في كود الواجهة.
4) لا تستخدم قاعدة بيانات. اجعل ملفات JSON داخل مستودع GitHub مصدر البيانات، وخزّن الملفات المرفوعة داخل مجلد أصول بالمستودع عند الإمكان. لأن Vercel لا يسمح بالكتابة الدائمة إلى ملفات المشروع أثناء التشغيل، أنشئ API/serverless endpoint آمنًا يستخدم GitHub API من الخادم لتحديث ملفات JSON والأصول ثم يبدأ نشر Vercel أو يعتمد على التكامل المتصل بالمستودع.
5) نفّذ التحقق من الصلاحيات على الخادم، وحدود أحجام الملفات، وأنواع الملفات، وأخطاء الرفع، وإعادة المحاولة، وتعارض التعديلات، وسجلّ تغييرات، وإمكانية الرجوع عن نسخة سابقة. لا تعرض نجاح الحفظ إلا بعد تأكيد GitHub API.
6) ادعم MP4 وMP4 Alpha حيث يسمح المشغل، SVG وGIF وWebP، وأضف مشغل SVGA/SVGA2.0 حقيقيًا باستخدام مكتبة مناسبة ومرخصة، مع توثيق طريقة التثبيت.
7) أضف README يشرح الإعداد والتشغيل والنشر، وقائمة متغيرات البيئة المطلوبة، وخطوات ضبط Google OAuth وGitHub/Vercel، من دون أسرار فعلية أو قيم وهمية تُعامل على أنها حقيقية.
8) اختبر الإضافة والتعديل والحذف والرفع والنشر وتحديث الصفحة. إذا تعذّر تنفيذ أي شيء داخل البيئة، اذكره بوضوح ولا تدّعِ نجاحه.

أخرج جميع الملفات اللازمة في هيكل مجلد واضح، ولا تحذف ميزات موجودة دون سبب. لا تكتفِ بإرجاع مقتطفات كود أو خطة؛ سلّم المشروع كاملًا.
