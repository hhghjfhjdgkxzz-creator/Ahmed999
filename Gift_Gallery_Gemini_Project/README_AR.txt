# Gift Gallery — Gemini 9 Upload Package

هذه حزمة مشروع تجريبي لواجهة Gift Gallery.

## محتويات المجلد
- `index.html`: ملف الموقع الكامل (HTML + CSS + JavaScript) في ملف واحد.
- `README_AR.txt`: تعليمات التشغيل والقيود الحالية.
- `GEMINI_PROMPT_AR.txt`: نص جاهز لرفعه مع المشروع إلى Gemini 9 وطلب تطويره.

## تجربة سريعة
1. فك ضغط الحزمة.
2. افتح `index.html` بمتصفح Chrome أو Edge.
3. جرّب لوحة الإدارة وأضف هدية بملف صغير.

## ملاحظات مهمة
- هذه نسخة Front-end تجريبية وليست خدمة منشورة.
- البيانات تُحفظ محليًا في IndexedDB على نفس المتصفح والجهاز.
- Google Sign-In غير مربوط بعد؛ زر الدخول تجريبي ويحتاج إعداد OAuth حقيقي.
- رفع ملفات من المتصفح لا يدمجها تلقائيًا في GitHub. لتحقيق ذلك يلزم backend آمن مع GitHub API وصلاحيات سرية محفوظة على الخادم.
- ملفات SVGA/SVGA2.0 تحتاج مشغل SVGA متخصصًا؛ هذه الحزمة لا تتضمن مكتبة SVGA.
- ملفات البيانات التوضيحية الموجودة في الموقع ليست بيانات إنتاجية.
