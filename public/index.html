البنية التقنية

دعم متكامل للصيغ والتخزين السحابي

مصمم ليعمل بكفاءة عالية محلياً وعلى Vercel مع GitHub Contents API وFirebase Auth.

01. معاينة SVGA وVAP والفيديو

يضم المعرض مشغل SVGA مدمج (عبر مكتبة svgaplayerweb المرخصة MIT) ومحرك محاكاة قناة الشفافية (Alpha Mask) لملفات الفيديو، مع إمكانية تبديل خلفية المسرح وتجربة الإطارات على صورة الحساب.

02. تخزين GitHub مع حماية تعارض SHA

يُحفظ الكتالوج في ملف data/gifts.json والملفات في public/assets مع فحص بصمة SHA والإصدار لمنع فقدان التعديلات المتزامنة، وسجل نسخ احتياطي فوري للاسترجاع.

03. أمان المسؤولين عبر Firebase Admin

لا توجد أي مفاتيح سرية في الواجهة الأمامية؛ يتم التحقق من رمز Google ID Token وبريد المسؤول على الخادم حصراً قبل السماح بأي عملية حفظ أو رفع.

لوحة التحكم الملكية

أنت مسجل الدخول

معاينة فورية للبطاقة

تُحفظ التعديلات في الخادم (ومستودع GitHub عند تفعيله) مع فحص تعارض النسخ SHA تلقائياً.

سجل الإصدارات والنسخ المحفوظة (Snapshots)

يحتفظ الخادم تلقائياً بنسخة عند كل عملية حفظ. يمكنك استرجاع أي إصدار سابق بضغطة واحدة.

تصدير الكتالوج (JSON Backup)

حمّل نسخة احتياطية كاملة بصيغة gifts.json تشمل جميع العناصر والإعدادات وبصمة SHA.

استيراد نسخة محفوظة

استرجع ملف JSON متوافق ليحل محل العناصر الحالية بعد مراجعتك وتأكيدك.

فحص المسارات التلقائي ومعالجة تعارض SHA

يختبر قراءة الكتالوج، الحفظ، اكتشاف تعارض التعديل المتزامن (409 SHA Conflict)، ورفع الملفات عملياً.

اضغط على "تشغيل الاختبار العملي الآن" لفحص جميع مسارات الخادم.
