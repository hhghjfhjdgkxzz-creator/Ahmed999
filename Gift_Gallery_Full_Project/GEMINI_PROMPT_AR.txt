تعليمات تطوير Gift Gallery:
افحص كل ملفات المشروع أولًا ثم أكمل التطوير بدون حذف الوظائف الحالية أو تغيير التصميم الأساسي بدون داعٍ.

المطلوب:
1. حافظ على واجهة عربية RTL وتصميم داكن فاخر ذهبي ومتجاوب.
2. أصلح أي أخطاء بناء أو تشغيل واختبر المسارات /api/gifts و/api/upload.
3. لا تضع أي GitHub token أو Firebase service account في ملفات الواجهة الأمامية.
4. حافظ على تسجيل الدخول عبر Firebase Google Authentication والتحقق من بريد المسؤول على الخادم.
5. لا تستخدم قاعدة بيانات. استمر في تخزين الكتالوج والملفات في GitHub عبر API من الخادم.
6. أضف اختبارات عملية للقراءة والحفظ والرفع، ومعالجة تعارض SHA إذا حصل تعديل متزامن.
7. أضف دعم مشغل SVGA/VAP فقط بعد اختيار مكتبة موثوقة ومتوافقة مع الترخيص، ولا تدّعِ أن الصيغ تعمل قبل اختبارها.
8. لا تضع بيانات اعتماد حقيقية داخل المشروع. استخدم متغيرات البيئة وملف .env.example.
9. لا تغيّر أسماء API أو مخطط gifts.json دون تحديث كل الملفات وREADME.
10. اذكر بوضوح ما تم اختباره فعليًا وما يحتاج إعدادات حسابات خارجية.
